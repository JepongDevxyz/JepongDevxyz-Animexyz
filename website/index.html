Usage

Start with the public default backend

AnimeXYZ uses Jikan REST API v4 for public anime metadata by default. You can also point it at an AnimeXYZ-compatible custom backend.

import AnimeXYZ from 'animexyz-api';

const api = new AnimeXYZ();
const popular = await api.popular({
  page: 1,
  limit: 10
});

Provider control

Bring your own authorized stream provider

Pass a streamProvider function when your app already has a legitimate provider integration. Without one, the public default returns available platform links from the metadata backend.

const api = new AnimeXYZ({
  streamProvider: async ({ id, episode }) => ({
    watchUrl: `https://your-provider.example/${id}/${episode}`
  })
});
